# 用人能理解的方式看机械臂参数

## `rad` 是什么

`rad` 是弧度，表示关节绕轴旋转的角度，不是距离：

```text
0 rad       = 0 度
0.5 rad     = 28.6 度
1.0 rad     = 57.3 度
1.2 rad     = 68.8 度
1.6 rad     = 91.7 度
3.1416 rad  = 180 度
```

换算公式：

```text
度数 = rad * 180 / 3.1415926
rad  = 度数 * 3.1415926 / 180
```

SDK 使用弧度，但以后可以在上层界面用度数输入；不要把弧度当作机械臂末端移动了多少厘米。

## “关节”对应哪一部分

机械臂的六个旋转轴叫 J1 到 J6，每个轴由一个电机驱动；夹爪另有第 7 个电机：

```text
SDK joints_rad[0] -> 电机 ID 1 -> J1
SDK joints_rad[1] -> 电机 ID 2 -> J2
SDK joints_rad[2] -> 电机 ID 3 -> J3
SDK joints_rad[3] -> 电机 ID 4 -> J4
SDK joints_rad[4] -> 电机 ID 5 -> J5
SDK joints_rad[5] -> 电机 ID 6 -> J6
SDK gripper_rad   -> 电机 ID 7 -> 夹爪
```

第 7 个电机建议称为“夹爪电机”或“夹爪”，不要把它和 J1～J6 混称为普通旋转关节。描述夹爪动作时使用“开合状态 + 位置 + 速度 + 力量”最清楚：

```text
夹爪全开：gripper_rad=1.6（目前采用的官方常用开位，约 91.7°）
本机实测全开反馈：约 2.032 rad（约 116.4°）；程序目标仍建议使用不超过配置上限的 2.0 rad
夹爪全闭：gripper_rad=0.0（闭合目标）
夹爪开到实测最大：逐步增大 gripper_rad，确认不撞限位后记录数值
夹爪合到物体：以 gripper_rad=0.0 为目标，但使用较低 max_tqu，接触后停止加力
```

这里的 `1.6` 是夹爪电机的弧度目标，不是两指之间的毫米距离；官方常用开位不等于每一把实际夹具的机械极限。没有物体时“合到最紧”实际上是碰到闭合机械止挡，因此不要用最大扭矩长时间顶住止挡。动作需求可直接写成“夹爪全开→夹住→夹爪闭合保持”，程序再转换成 `gripper_control(pos, vel, max_tqu)`。

数组里的第一个数永远是 J1，第二个数永远是 J2，以此类推。正负号表示该轴相对于厂家零点的两个旋转方向；零点、方向、减速比和限位由官方 `Follower.yaml` 与电机参数加载，用户不需要把角度手算成编码器计数。

## 参数怎样变成机械运动

当程序执行：

```python
robot.moveJ([j1, j2, j3, j4, j5, j6], duration=8.0, iswait=True)
```

发生的是：

1. 程序把六个目标角度交给官方 SDK。
2. SDK 根据 `Follower.yaml` 找到对应的 CAN 电机、方向、零点和限制。
3. SDK 在 `duration` 秒内生成从当前角度到目标角度的关节轨迹。
4. 控制盒把目标发送给电机闭环控制器，电机带动对应关节转到目标角度。

所以，`moveJ` 中的数字描述的是“每个关节最终转到哪个角度”，不是“末端移动到哪个坐标”。末端的 X/Y/Z 位置需要正运动学或 `moveL`，并且同一个末端位置可能有多种关节姿态。

## 这次 `1.20 rad` 拒绝的具体含义

预览时目标 `upright_demo` 为：

```text
目标 J1..J6 = [1.574, 1.199, 1.199, 0.400, 0.000, -0.075] rad
```

当前反馈大约为：

```text
当前 J1..J6 = [1.557, -0.002, 0.000, 0.002, -0.065, 0.047] rad
```

J2 需要从约 `0°` 转到 `68.7°`，J3 也需要从约 `0°` 转到 `68.7°`。项目保护规则把任一关节超过 `0.8 rad`（约 `45.8°`）的目标先拦住，让人检查路径；这不是厂家宣称的机械极限，也不是故障提示。

## 扭矩是什么

扭矩是电机“拧动关节的力量”，单位是 N·m（牛顿·米），类似拧螺丝时的用力大小：

- `position`：关节转到哪里
- `velocity`：转得多快
- `torque`：当前用了多大旋转力量
- `fault`：电机故障码，正常应为 `0`

`moveJ` 主要给位置和时间；`max_tqu` 是可选的扭矩上限。夹爪使用 `gripper_control(pos, vel, max_tqu)`，其中 `pos` 是夹爪角度、`vel` 是夹爪速度、`max_tqu` 是夹爪力量上限。扭矩上限不是“要转到的角度”，不能用扭矩代替位置。

## 最容易记住的方式

```text
姿态 = 六个关节角 + 一个夹爪角
动作 = 从当前姿态到目标姿态，花多少秒完成
力量 = 运动过程中允许电机/夹爪施加多大扭矩
```

实际开发时不需要手写这些角度。让人摆好姿态后运行 `save-current 名称`，程序读取编码器反馈并保存为命名姿态；以后说“回到这个名称”，程序再把保存的七个角度交给 SDK。
